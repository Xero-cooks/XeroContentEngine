# Orbit Studio Skill

A configurable agent skill for narration-led motion-design videos: explainers, recurring creator reels, product walkthroughs and technical teaching. Start from a brand profile, preserve real narration timing, produce editable compositions, and validate the final delivery instead of stopping at a render log.

**Open-source instructions + tested planning utilities, not a bundled video renderer.** The example preset reflects the original Orbit creator's workflow; your brand, language, mascot, fonts, backgrounds, tools and accounts are configurable. Composio is optional.

## Quick start

Python 3.10+; the included utilities use only the standard library.

```bash
git clone https://github.com/Xero-cooks/orbit-studio-skill.git
cd orbit-studio-skill
python scripts/init_profile.py --preset neutral --output config/profile.local.json
# Edit config/profile.local.json: brand, format, fonts, assets and optional tools.
python scripts/check_profile.py config/profile.local.json
python scripts/new_episode.py demo_01 --profile config/profile.local.json --output-root episodes
python scripts/retime.py --input examples/inputs/timing.json --output /tmp/orbit-retimed.json
python -m unittest discover -s tests -v
```

Use `--preset orbit` to copy the clearly labeled teal/Geist/Hinglish/robot example instead. Missing assets are reported, not invented. Profile/episode scaffolding does **not** render a video.

## Install the skill

- **File-based agents:** place this folder under the agent's supported skills directory and point it at root `SKILL.md`. For agents that support the `.agents/skills/` convention, use `.agents/skills/orbit-studio/`; check your agent's own installation rules.
- **Composio:** use your organization's skill-management interface to create/import the complete `SKILL.md`, then load its returned slug. Do not copy the original creator's skill ID/account IDs. This repo does not require a Composio account.
- **Notion:** store the instructions in your own Skills setup and supply the profile/assets. Marking/importing a skill is a separate workspace action; cloning this repository does not install it automatically.

## What you can personalize

| Area | Examples |
|---|---|
| Brand and language | Studio name, Hinglish/English/other supplied narration, tone, palette |
| Character | Approved robot/mascot, different pose names, or no mascot |
| Typography | Your licensed font file, weights and visible-token conventions |
| Output | Portrait/landscape, resolution, fps and safe-area checks |
| Backgrounds | Your approved source library and motion/readability rules |
| Audio | Narration source, sparse SFX, loudness/peak preferences |
| Tools | EffectCraft example adapter, another verified renderer, optional Composio/desktop adapter |
| Publishing | Your connected accounts/platforms, visibility and explicit approval |

Copy example files; never put credentials in profiles. Native app templates, font files, backgrounds and accounts belong to the user, not this repository. See [Personalization](docs/PERSONALIZATION.md).

## Use cases

1. **Recurring explainer series:** preserve a recognizable brand/mascot while changing the actual episode script and timing.
2. **Character-free product demo:** use a neutral profile, measured captions, diagrams and screen captures with the user's consent.
3. **Multilingual creator reels:** keep supplied narration, review mixed-language alignment, and stage emphasis without blanket speed-up.
4. **Native production handoff:** transfer an editable project with dependency checks, audio stems and truthful QA status.
5. **Cross-platform adaptation:** create a separate layout/profile for another aspect ratio; recheck overlays instead of blindly cropping.

## Honest limits

This is not a one-prompt generator, an actual 3D/PBR rig, phoneme lip-sync, a scientific benchmark, or an always-running automation. It cannot guarantee another editor supports EffectCraft commands. Renderer setup, supplied assets, factual review and audiovisual inspection still matter. No paid generation or posting happens by default. The installed original creator kit may contain additional private/native assets not shipped here.
