# Input and output examples

## A. Original creator's workflow as a preset

Input: `config/profiles/orbit.example.json` plus your script/narration and a supplied approved character library. This demonstrates Hinglish, teal/Geist and character-led staging. It contains no actual account IDs, machine paths, recordings or native rig.

Output: an episode scaffold, scene/timing plan and, AFTER real production with your installed tools/assets, a validated video and editable project. The first two are supported by repository utilities; the last two require the external workflow.

## B. Another creator / no mascot

Copy the neutral preset. Set brand.name, language, your licensed font, output size/fps and actual renderer/template paths. Leave character.enabled false. A sample request: “Create a 45-second English product walkthrough with quiet teaching diagrams, no mascot, and a private draft only.” No Composio account or posting is assumed.

## C. Retiming

`examples/inputs/timing.json` inserts pauses at 2.0s and 6.0s. Run the supplied script and compare with `examples/outputs/retimed.json`. Word/scene/SFX cues share the same map. This is an actual deterministic script output, not a video or forced alignment.

## D. Handoff

The illustrative final-delivery JSON deliberately uses null verification/hash fields and status NOT_RENDERED_EXAMPLE. Replace them with measurements only after a real job. The scaffold receipt is generated by the tested helper and honestly reports unrendered/missing-asset state.
