# QA and delivery checklist

- [ ] Profile and supplied asset inventory resolved; missing assets are disclosed.
- [ ] Approved script/narration preserved; illustrative values are labeled.
- [ ] One consistent source/output clock; new alignment and reviewed uncertainties.
- [ ] Real font measurements, weight axes and longest captions checked.
- [ ] Background/crop/contrast and mascot hierarchy correct for this profile.
- [ ] Static proofs and full timeline draft inspected; transition frames and audio reviewed.
- [ ] No unwanted frozen layouts, duplicated poses, flash overlap, clipping or stale text.
- [ ] All chunks validated; exact N frames and final remainder accounted for.
- [ ] Full final decode passes; dimensions/fps/audio/color metadata/loudness/peak measured.
- [ ] Collected editable project reopened and rendered; missing fonts/assets disclosed.
- [ ] Actual MP4/ZIP transfer validated with byte counts and hashes where supported.
- [ ] Secrets and nonredistributable/private assets excluded from public packages.
- [ ] Optional posting explicitly authorized and confirmed by real provider receipts.

A script/scaffold test is not a renderer test. ffprobe is not a semantic review. A sparse frame sample is not all-frame semantic proof. A waveform envelope is not phoneme alignment. Missing fields must be marked unknown/pending, not filled with invented success values.
