# Optional integrations

Core planning utilities are offline and do not call Composio, paid APIs or posting endpoints.

## Composio / MCP

Discover current tool schemas and authorized accounts. Search/load the organization's installed skill rather than inventing an ID. Create/update/import through the organization's supported interface; keep actual IDs outside public examples. The original creator's saved skill can be updated independently of this repository, but cloning does not update an installed copy.

Composio is one provider example. A direct authorized API or local CLI can be substituted only when capabilities and authentication are verified. Never copy credentials between users, log secrets, assume an account or request fresh paid generation just because an integration exists.

## Local / remote desktop

Set a user-supplied adapter/capability in local configuration. Use targeted background file/native CLI work where supported; do not hijack unrelated foreground activity or modify unrelated services. XeroPC is the original workflow's example name, not a required endpoint or bundled service.

## Figma / native editor

Inspect write/export capability. Read-only access can produce/export Figma-ready SVG assets, not evidence that they were authored through a write-enabled Figma connection. No renderer or third-party native templates are bundled.

## Reels / Shorts and other platforms

Configure platforms/accounts for the user. Defaults list reels/shorts only as examples, and publishing is disabled. Explicitly authorize exact content, destination and visibility before posting. Report returned IDs/URLs only after successful provider responses; do not fake sample posting receipts. Do not upload private narration or credentials as public repository examples.
