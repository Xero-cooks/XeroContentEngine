# Workflow and handoff

## 1. Preflight
Resolve profile; collect approved script, immutable narration, actual timings, licensed/user-provided assets and verified native project/tooling. Measure real duration/fps/sample rate and longest caption widths. Preserve original files. Create episode-local STATE.md and an input inventory.

## 2. Editorial plan
Map hooks/comedy to hero/dialogue, mechanisms to quiet teaching, evidence to verified/labeled diagrams, and CTA to a truthful next step. Use optional mascot performances, not a permanent slide/character/caption stack. Record source/output time, background/crop/seed, emphasis/SFX and uncertainty per scene.

## 3. Build a copy
Duplicate supplied templates/rigs. Never modify canonical libraries or approved episodes. Keep text, shapes and character parts editable. Measure actual font widths and configure variable weight axes. Make actual claims/values explicit; do not draw fictitious benchmark bars. Optional motion should serve attention and not shake text/formulas.

## 4. One source-to-output clock
For inserted pauses, apply `t + sum(d for at,d in pauses if at <= t)` to ALL cues. Exactly at an insertion point maps after the inserted pause. The script supports this stated boundary convention only; it does not cut, stretch or align audio. Record source and output values. Cuts/time-stretch need a different, explicit piecewise timeline.

## 5. Proof and master
Check representative frames and full draft motion/audio, then run resumable native chunks where useful. Resolve exact integer frames and final chunk remainder. Verify process status and app JSON success independently. An output file may exist after an unsuccessful partial native save.

## 6. Delivery and optional posting
Decode/QC the master, measure encoded loudness/peak, collect dependencies, reopen and render a portability proof. Deliver actual retrievable files. A local path/ffprobe record is not a final audiovisual review. Publish only to a discovered user-authorized account after authorization for the exact destination/content.

## Next-agent state
Record effective profile, immutable inputs, actual output paths, timeline mapping, completed valid chunks, current PID/job ID and monitoring, QA results, remaining questions and limitations. Never substitute old episode timing or make an indefinite background-reasoning promise.
